# 보임(BOIM) — 한국 업체 찾기

Dify 에이전트·챗플로·워크플로에서 한국 업체, 공공 조달 실적 업체, 진행 중인 공공기관 입찰 공고를 찾습니다. 데이터는 공공 데이터로 만든 읽기 전용 업체 정보 사이트 [보임(boim.io)](https://boim.io)에서 오고, 결과마다 출처 주소가 붙습니다.

## 도구

| 도구 | 찾는 것 | 입력 예 |
|---|---|---|
| 동네 가게 찾기 (`find_businesses`) | 전국 전 업종 영업 중 업체(약 276만 곳, 소분류 247개)를 시·도·시군구(·행정동)와 업종·상호로 찾습니다. 상호·업종·행정동만 있고 상세 주소·전화는 없습니다. | 지역 `세종 보람동`, 업종 `미용실` |
| 업체 찾기 (`search_vendors`) | 조달청 공공 데이터(계약 품목·최근 1년 공공 납품, 전 품목)로 만든 업체 카드 약 7.6만 곳 — 국세청 사업자 상태와 업체가 보임에 직접 올린 정보까지. | 품명 `안내판`, 지역 `세종` |
| 입찰 공고 찾기 (`find_public_bids`) | 나라장터·국방전자조달·LH·한국수자원공사·누리장터의 마감 전 공고를 모든 분야에서 찾습니다. 하루 두 번 갱신, 마감이 가까운 순서, 공고 원문 링크 포함. | 분야 `청소`, 종류 용역 |

한 번에 5건까지 보여 주고, 전체 건수와 boim.io의 전체 목록 주소, 답에 붙일 출처 한 줄(`cite`)을 함께 줍니다. 순서는 업체 = 이름순(보임에 직접 등록한 업체 먼저), 조달 업체 = 관련도 → 카드 정보가 갖춰진 정도 → 날마다 섞기, 입찰 = 마감순입니다. 순위·평가·유료 노출이 아닙니다.

## 설치

1. Dify 마켓플레이스에서 **BOIM — Korean Business Finder**를 설치합니다.
2. API 키·가입·인증 정보가 필요 없습니다. 설치하면 바로 씁니다.
3. 에이전트·챗플로·워크플로 노드에 도구를 붙입니다.

## 쓰는 법

- **에이전트·챗플로**: 한국어나 영어로 묻습니다. 예: `세종 보람동 미용실 알려 줘`, "Find cafés in Seoul Gangnam-gu". 모델이 지역·업종(품명)·상호를 채웁니다.
- **워크플로**: 변수를 도구 입력에 연결합니다. 결과는 `text`(읽기 쉬운 요약)와 `json`(보임 원본 결과 — 주소·건수·`more`·`cite`, 조달 업체는 확인 근거 `checks`)으로 나옵니다.
- 지역은 시·도 + 시·군·구(필요하면 행정동)로 적습니다: `서울 강남구`, `대전 유성구`, `세종 보람동`. `Seoul Gangnam-gu` 같은 로마자도 됩니다.
- 전화·홈페이지·가격은 업체가 보임에 직접 등록한 경우에만 나옵니다. 입찰 참가 자격(지역 제한·직접생산 확인 등)은 공고 원문에서 확인하세요.

## 연결 조건

플러그인은 고정 주소 하나 `https://boim.io/api/mcp`(보임 공개 MCP 서버, HTTPS JSON-RPC `tools/call`)만 부르고, 시간 제한은 20초입니다. Dify가 `boim.io`로 나가는 인터넷 연결이 필요합니다. 짧은 시간에 아주 많이 부르면 잠시 막힐 수 있습니다(HTTP 429·403) — 몇 분 뒤 다시 하세요.

## 데이터 출처

공공데이터포털(data.go.kr)의 정부 공공 데이터: 소상공인시장진흥공단 상가(상권)정보, 조달청 종합쇼핑몰 품목·납품요구·계약 정보, 국세청 사업자등록 상태, 나라장터·국방전자조달·LH·한국수자원공사·누리장터 입찰 공고. 대표자 이름·상세 주소·사업자등록번호는 싣지 않습니다.

## 개인정보

플러그인은 아무것도 저장하지 않고, 부를 때마다 검색 조건만 boim.io로 보냅니다. 자세한 내용은 [PRIVACY.md](../PRIVACY.md)와 [보임 개인정보처리방침](https://boim.io/privacy/)을 보세요.
